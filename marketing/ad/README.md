# ROMGrid launch ad

Production files for the first ROMGrid promotional video.

## Master version

- Format: vertical 9:16
- Resolution: 1080 x 1920
- Duration: 24 seconds
- Frame rate: 30 fps
- Language: English
- Audio: music and interface sound design; no voice-over
- Core promise: generate a consistent icon set for an entire library in one pass

## Game selection

The recording should use a visually varied set that is familiar to emulation
communities without making the video feel Nintendo-specific:

1. Pokemon Emerald
2. Castlevania: Symphony of the Night
3. Metal Gear Solid
4. Tekken 3
5. Sonic Adventure 2
6. Burnout 3: Takedown
7. Persona 3 Portable
8. God of War: Chains of Olympus

If a title has poor or inconsistent artwork in SteamGridDB, replace it with
Silent Hill, Final Fantasy VII, Crazy Taxi, or Gran Turismo 4.

## Deliverables

- `romgrid-ad-vertical-1080x1920.mp4`
- `romgrid-ad-horizontal-1920x1080.mp4` (adaptation after vertical approval)
- Editable Kdenlive project
- SVG title cards and logo assets
- Clean screen recordings without music

## Brand proposal

The editable identity refresh lives in `brand/`:

- `romgrid-mark.svg`: app icon and favicon source
- `romgrid-wordmark.svg`: horizontal navigation and end-card lockup
- `romgrid-brand-board.svg`: presentation and small-size checks

PNG previews are generated from the SVG sources and are not the editable
masters.

The horizontal wordmark is also the visual basis for the 1200 x 630 Open Graph
image shown by messaging apps and social networks when a ROMGrid link is shared.

## Production tools

- OBS Studio: browser capture
- Kdenlive: edit, titles, motion, and sound design
- FFmpeg: final compression and format variants
- Affinity or Inkscape: logo and vector assets

Do not include ROM downloads, emulator configuration, publisher logos in the
end card, or claims of affiliation with game publishers.
